2. Kali Linux Tool Suite Provisioning

Execute this bash bootstrap script inside your fresh Kali installation to install additional offensive utilities and wordlists needed for CCY4202:

bash — root@kali-lab:~# setup_tools.sh 
#!/usr/bin/env bash
# Update package repositories
sudo apt update && sudo apt upgrade -y

# Install essential wordlists & discovery tools
sudo apt install -y seclists gobuster feroxbuster eyewitness chisel evil-winrm

# Unpack rockyou wordlist
if [ -f /usr/share/wordlists/rockyou.txt.gz ]; then
  sudo gunzip /usr/share/wordlists/rockyou.txt.gz
  echo "[+] rockyou.txt successfully uncompressed."
fi

echo "[+] Lab tools installation complete."
