TCP 3-Way Handshake & Port State Deduction

State / Sequence Kernel Response Deducted State Pentester Exploitation / Operational Reality Source
Client [SYN] [SYN-ACK] OPEN Target service is listening and willing to allocate socket buffers. Primary exploit target. Lab 01
Client [SYN] [RST] (Reset) CLOSED Host OS kernel actively rejects packet; indicates host is alive but no daemon is bound. Lab 01
Client [SYN] Timeout / No Reply FILTERED Packet dropped silently by an intervening firewall rule or host-based iptables/ACL. Lab 01
SYN Stealth Scan SYN ➔ SYN-ACK ➔ RST HALF-OPEN Client tears down connection before final ACK to evade web server application-layer logs. Lab 01
TCP vs. UDP Stateful vs Stateless L4 TRADE-OFF TCP guarantees delivery for reverse shells; UDP allows spoofed traffic but is silent when open. Lab 01
