Lab 03: SQL Injection

Lab 04: Cross-Site Scripting (XSS)

Get your own JavaScript running on a page the victim trusts. Land DOM XSS live on Juice Shop, steal a logged-in session out of localStorage and hijack it, then exfil the token silently. Climb the PortSwigger ladder for reflected, stored, and attribute-breakout XSS.

Lab 05: Broken Access Control

No payload this time. Change one number and read another user's basket (IDOR), list every account and spot the admin through the API (BOLA), then beat the write guard with HTTP parameter pollution. Number one on the OWASP list, and the most common serious bug in real apps.

Week 5 · Web Exploitation Open Lab 05 →

Lab 06: File Upload to Web Shell & Command Injection

The bridge from web hacking to a shell on the box. Find misconfig on Juice Shop (directory listing, null-byte bypass, no CSP), upload a PHP web shell for remote code execution on PortSwigger, beat Content-Type and extension filters, then command-inject your way to a reverse shell.

Lab 07: Recon, Scanning & Enumeration

The loop-back to where real engagements start. Turn one IP into a full map: Nmap scan types and service detection, then enumerate HTTP and SMB with gobuster and enum4linux. Build the attack surface map on TryHackMe and pick the weakest door.

Lab 08: Service Exploitation & Initial Access

Turn a version number into a shell. Look up a known flaw with searchsploit, fire it with the Metasploit flow (EternalBlue, the lab version of the Maersk story), understand bind vs reverse shells, then run a raw public exploit by hand with no Metasploit at all.

Lab 09: Privilege Escalation

Turn a nobody shell into root. Run sudo -l and GTFOBins for the fast win, hunt SUID binaries and writable cron jobs, then PATH hijacking and the Windows paths to SYSTEM. The step that turns a foothold into total compromise.
