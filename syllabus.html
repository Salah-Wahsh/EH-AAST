CCY4202: Ethical Hacking & Penetration Testing

Official course specification, instructional syllabus, evaluation metrics, and rules of engagement for 4th-year cybersecurity engineering students.

🎯
Course Focus

Methodologies, technical vulnerability assessment, exploitation primitives, defensive circumvention, and post-exploitation analytics.

📚
Prerequisites

CCY3101 Computer Networks, CCY3202 Operating Systems Internals, and proficiency in Linux CLI & Python scripting.

Course Learning Outcomes (CLOs)

  • CLO 1 Execute structured reconnaissance and OSINT collection adhering to the Penetration Testing Execution Standard (PTES).
  • CLO 2 Analyze network and transport layer packet exchanges to distinguish stealth scan signatures from defensive honeypots.
  • CLO 3 Discover, triage, and calculate CVSS v3.1 impact scores for enterprise server and web application vulnerabilities.
  • CLO 4 Demonstrate controlled remote exploitation and staging of Meterpreter payloads against unpatched network daemons.
  • CLO 5 Perform privilege escalation on UNIX and Windows targets and pivot through multi-homed routers into deep subnets.

Assessment & Grading Breakdown

Evaluation Item Weight Format & Details
Laboratory Modules & Quizzes 35% 7 weekly interactive labs + digital verification quizzes (5% per module)
Midterm Practical Exam 25% Live 2-hour timed assessment: Nmap scanning, CVSS scoring & Web SQLi exploitation
Capstone CTF & Pentest Report 30% Multi-tier enterprise network penetration test + formal executive report
Classroom Lab Engagement 10% Oral defense of thought questions, peer code review, and debug teamwork
